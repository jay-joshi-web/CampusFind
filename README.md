# CampusFind — SPSU Lost & Found Mini Project

A simple beginner-level Web Development mini project for SPSU.

## Features
- Report a lost item.
- Report a found item.
- View recent reports.
- Filter reports by Lost or Found.
- Delete a report.
- Basic JavaScript form validation.
- Express API and MySQL database.

## Technologies used
- HTML5
- CSS3
- JavaScript
- Node.js and Express.js
- Fetch API and JSON
- MySQL
- Git and GitHub (for version control)

## Setup
1. Open MySQL Workbench and run `database/campusfind.sql`.
2. Open `server.js` and replace `YOUR_MYSQL_PASSWORD` with your MySQL password.
3. Open a terminal in the CampusFind folder.
4. Run `npm install`.
5. Run `npm start`.
6. Visit `http://localhost:3000`.

## Project scope
This is an academic mini project with a deliberately simple design and feature set. It does not currently include student login, admin roles, image uploads, or online deployment.
